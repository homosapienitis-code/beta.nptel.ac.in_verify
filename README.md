# Independent certificate display page

This site displays the certificate PDF supplied by the owner. It is not an official NPTEL verification service and does not create or modify any NPTEL record.

## Publish with GitHub Pages

1. Create a GitHub repository, for example `certificate-verify`.
2. Upload the **contents** of this folder (the root `index.html` and the `verify/` folder).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. After GitHub Pages publishes the site, the page will be available at:

   `https://YOUR-USERNAME.github.io/certificate-verify/verify/NOC-BJ4S-F9FK-03Z5C/`

Replace `YOUR-USERNAME` with your GitHub username. GitHub Pages can take a few minutes to publish.

## Important
- You cannot host a page on `beta.nptel.ac.in`; that domain is controlled by NPTEL.
- This page is independently hosted and clearly identifies itself as unofficial.
- Keep `certificate.pdf` in the same folder as the `index.html` in `verify/NOC-BJ4S-F9FK-03Z5C/`.
